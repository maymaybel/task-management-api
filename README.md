
# Task Management API

## Project Description
This project is an initial API contract for a Task Management System.

The system allows users to manage their accounts and tasks.

## Resources
- Users
- Tasks

## API Endpoints

### Users
- GET /users
- GET /users/{id}
- POST /users
- PUT /users/{id}
- DELETE /users/{id}

### Tasks
- GET /tasks
- GET /tasks/{id}
- POST /tasks
- PUT /tasks/{id}
- DELETE /tasks/{id}
